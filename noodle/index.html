noodle

A capability for AI and humans to generate deterministic tests using plain English BDD.

No selectors. No page objects. No step definitions. No code. Tell Noodle what to test — it writes the noodles, so you don't have to.

get noodle see how it works
login.feature gherkin 
@web @smoke
Scenario: Valid user can log in
  Given User is on "{env:BUSTERBLOCK}"
  When User enters {env:BB_USER} in the username field
  And User clicks the login button
  Then User should see "VHS Catalog"
$ noodle run --tags @smoke 1 passed

plain english in

Write the scenario the way you'd say it out loud. Noodle resolves the selectors, the waits and the page objects for you.

deterministic out

The same feature file runs the same way every time — local, CI, headed or headless. Generation is assisted; execution is not a guess.

ai + human native

A tester and an agent write the exact same artefact. One language, one runner, one report — no translation layer between them.

install

Noodle is in private alpha — the repository is invite-only. For access, contact gino.sanpascual@gmail.com.

install.sh macos 
# macOS — the Windows 11 and Linux paths ship in the README
curl -LsSf https://astral.sh/uv/install.sh | sh
git clone https://github.com/gheeno/noodle.git && cd noodle
git checkout 9.11.0-alpha  # pin to a release — main moves several times a day
uv venv && uv tool install --editable ".[all]" --with-executables-from playwright
playwright install chromium
noodle doctor
$ noodle doctor engine ready

Installed once, like git — your tests live in their own workspace, never inside the clone.
